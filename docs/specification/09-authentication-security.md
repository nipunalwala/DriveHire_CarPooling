# 09 · Authentication and security

Normalize email by trim/lowercase only. Argon2id passwords; explicit configured hashing cost benchmarked in deployment. Email verification OTP expires10minutes, at most5 wrong attempts; resend cooldown60seconds and route/account/IP limits. Password reset uses256-bit random token, stored hash,15minute expiry and one use; newer request invalidates prior challenge. Generic acknowledgements prevent email enumeration. Account creation/reset challenge and encrypted auth-email outbox entry commit atomically; no raw secret in logs or safe payload.

Access JWT15minutes, fixed refresh-family absolute expiry30days. Opaque refresh secrets are hashed; rotation locks token, consumes once and emits one successor; replay revokes the family. HttpOnly SameSite=Lax cookie, Secure in staging/production, explicit path and allowlisted Origin check for cookie writes. Tokens stay in memory, never localStorage. Logout, reset, session revoke and suspension invalidate current access through DB account/session/token-version checks. Cross-tab refresh coordination prevents accidental replay. Server role/object checks are mandatory on every private operation.

Private uploads: size/type/magic validation, generated opaque key, quarantine and ClamAV CLEAN before submission/content access. Authorized owner or administrator download; no static paths, direct storage keys, traversal or executable content. Parameterized queries, strict Zod DTOs, plain-text rendering, no dangerous HTML, request size limits and redacted correlated logs remain. Runtime cannot perform DDL, update/delete immutable audit/history or change vehicle owner. Encryption keys, cookie/JWT secrets and SMTP credentials are configured privately, never seeded or committed.

Protect self/last-admin suspension and own verification approval; keep reasoned audit for administrator actions and evidence reads. Test foreign object IDs, role spoofing, stale versions, duplicate idempotency keys, upload polyglots, CSRF/origin, refresh races and immediate revocation in owning milestones. No public-release claim without final security evidence.
