Public safe summary embeds make/model/seats and host display name; never registration, contact, evidence or passenger roster. Published times/cities/seat offer/price are immutable; cancel/recreate to change. Full is a derived capacity label; published full rides remain PUBLISHED.

Search by city IDs, origin-local departure calendar day and requested seats; timezone conversion to UTC ranges is server-side. Only qualifying unstarted PUBLISHED rides before join cutoff with enough capacity appear. Join cutoff starts_at-15min inclusive. Verified non-host PASSENGER submits seats and Idempotency-Key. Lock relevant users then carpool; check published/unstarted/current qualification/cutoff; atomically guarded increment plus ACCEPTED participation insert. Unique ACCEPTED(carpool_id,passenger_id) and count bounds protect duplicate/overflow; no PENDING or host accept/reject state. Host can read participant display names/counts, not approve requests.

Passenger cancellation>=15min before start or reasoned admin override pre-start transitions ACCEPTED->CANCELLED and decrements once; repeated cancellation does not decrement. Whole-ride pre-start cancellation terminalizes accepted requests, zeros count, terminalizes trip and releases both reservations atomically. Unstarted expiry at starts_at+30min uses EXPIRED consistently. No seat changes after actual start. On completion/failure preserve ACCEPTED participation as historical record; derived available seats are not bookable after start/terminal state. Manual trip states and overrun guard use the shared lifecycle.
