# DriveHire & CarPooling Platform

Phase01 implements the approved project foundation: a TypeScript npm workspace, operational Express API/worker, browser-safe shared contracts, minimal React routing shell, isolated PostgreSQL/Mailpit/ClamAV services and CI. Product workflows begin in later phases. Historical application commits remain recoverable in this same repository; no new GitHub repository or license was created.

Start with [project overview](docs/specification/00-project-overview.md), [architecture](docs/specification/06-system-architecture.md), [business rules](docs/specification/05-business-rules.md), [API contract](docs/api/openapi.json), [UI specification](docs/specification/10-frontend-ui-ux-specification.md) and [master execution guide](docs/implementation-prompts/00-MASTER-EXECUTION-GUIDE.md). The [roadmap](docs/planning/roadmap.md), [workspace assessment](docs/planning/workspace-assessment.md), [planning review](docs/planning/review.md) and [traceability](docs/specification/19-requirements-traceability.md) show the approval baseline.

Use [local development instructions](docs/operations/development.md) for Node24.22.0/npm11.19.1, `npm ci`, local environment initialization, service startup and verification. `/api/v1/health` is live; `/api/v1/ready` deliberately returns503 before Phase02 schema/worker prerequisites exist. Current scope and approval are recorded in the [approval log](docs/planning/approval-log.md). The next prompt is [02 Database Schema and Migrations](docs/implementation-prompts/02-DATABASE-SCHEMA-MIGRATIONS.md).

Public explanatory imagery will be generated as original project assets during the UI phases, recorded in [image asset policy](docs/design/image-assets.md). Impeccable and Superpowers workflows are encoded in the guide and phase prompts.

Run `npm test`, `npm run typecheck`, `npm run lint`, `npm run format:check`, `npm run docs:check`, and `npm run build`. Dedicated service checks use `npm run test:integration` and `npm run infra:check`; see development instructions before starting them. End-to-end product and Prisma migration commands explicitly report unavailable until their owning phase. No production deployment or payment/GPS functionality is present.
