# DriveHire visual system

Milestone03 establishes an operational interface for creating, verifying and managing an account. Preserve PRODUCT.md truth and docs/design/auth-interface-direction.md. Frontend ownership belongs to GPT-6.1 Sol in Codex with Impeccable; OpenCode owns backend work.

Use deep teal text (#163d38), teal actions (#166453), warm neutral canvas (#f8f8f2), white form surfaces and pale leaf accents (#d9e8b7). Secondary text is #526a64; danger and success states include explicit words, never color alone. Inherit the foundation's system typography for forms and headings, with restrained tracking and clear size hierarchy. Body text is16px by default; supportive instructions are12–14px.

The public shell has a compact wordmark and account navigation. Authentication pairs a task introduction with one form, stacked on mobile. Desktop form width comes from a two-column max1240px shell; at740px it becomes a single column. At320px the form remains the priority. Form controls are at least48px tall, have visible labels, autocomplete metadata and high-contrast focus rings. Group inputs by purpose and preserve entered data on errors.

White form panels use14px radius and a quiet downward shadow. Controls use6–7px radii. Borders delimit inputs and major sections; do not wrap every item in a card. Shared buttons, fields, badges and feedback states carry later features. Navigation and form results move focus deliberately; reduced-motion preferences disable transitions.

Authentication screens contain no decorative raster placeholders, metrics, testimonials or fabricated listings. Original service imagery is generated and integrated in07 with recorded provenance and responsive crops. The landing page remains explicit about unavailable booking journeys until their implementation.

Validate keyboard behavior, error focus, responsive overflow, loading/disabled controls and actual server responses. Inspect desktop and mobile captures in a bounded visual pass. Keep tokens in memory and use an HttpOnly refresh cookie; no browser localStorage credentials.
